# Лабораторна робота №2 — Акустична варта

Простий навчальний сайт компанії, створений за допомогою HTML і CSS без JavaScript та CSS-фреймворків.

## Структура проєкту
- `index.html` — HTML-сторінка.
- `css/style.css` — стилі сайту.
- `images/` — папка для зображень, якщо вони знадобляться.

## Як запустити
Відкрийте файл `index.html` у браузері.

## Що продемонстровано
- Семантичні елементи `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- Селектори елементів, класів, ID, атрибутів, універсальний селектор і групування.
- Приклад specificity: `.note` і `#measurements .note`.
- Box Model: `width`, `height`/`min-height`, `margin`, `padding`, `border`, `box-sizing`.
- `display: block` та `display: inline-block`.
- `position: relative` і `position: absolute` у попередженні.
- `transition` і зміна кольору кнопки при наведенні.
- Форма з `label`, `input`, `select`, `option`, `textarea`, `button` і `required`.

Дані вимірювань є вигаданими. Форма не надсилає дані на сервер.
